# Cadence Implementation

This directory is reserved for project-owned Cadence artifacts that can legally be redistributed.

Recommended additions:

```text
schematic/
    conventional-comparator.png
    proposed-comparator.png

testbench/
    comparator-testbench.png

netlist/
    exported-netlist.sp   # only if legally distributable

simulation_setup/
    setup-notes.md
```

Do not commit proprietary GPDK045/foundry files, restricted BSIM model files, Cadence installation files, license files, or large PSF/raw databases.
